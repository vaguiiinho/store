# ADRs

Este diretorio registra decisoes arquiteturais relevantes.

## Como usar

- Cada decisao importante deve gerar um arquivo numerado.
- O nome deve ser curto e descritivo.
- O conteudo deve explicar contexto, decisao, alternativas e impacto.
