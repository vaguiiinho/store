# ADR 0002 - MVP de Produtos Fisicos

## Contexto

O escopo inicial do projeto precisa ser reduzido para permitir entrega rapida.

## Decisao

Limitar a v1 a uma loja de produtos fisicos.

## Razao

- Simplifica checkout e operacao.
- Mantem a modelagem de entrega mais direta.
- Evita complexidade desnecessaria de produtos digitais ou servicos.

## Alternativas Consideradas

- Marketplace.
- Produtos digitais.
- Servicos e agendamentos.

## Impacto

- Escopo menor.
- Menos risco tecnico e operacional.
- Base mais clara para evolucao futura.
