# Documentacao do Projeto

Este diretorio organiza a documentacao da loja virtual.

## Ordem de leitura recomendada

1. `docs/prd-loja-virtual.md` para entender o produto.
2. `docs/arquitetura.md` para entender a estrutura tecnica.
3. `docs/entidades.md` para entender o dominio.
4. `docs/fluxos.md` para entender as jornadas principais.
5. `docs/api.md` para entender os contratos esperados.
6. `docs/implementacao-tasks.md` para executar o plano.
7. `docs/roadmap.md` para ver a evolucao por fase.
8. `docs/runbook.md` para operacao e suporte.

## Subdiretorios

- `docs/adr/`: decisoes arquiteturais registradas.
