# Project Kickoff

Use esta skill quando estiver iniciando um novo projeto ou adaptando este ambiente para uma nova base de codigo.

## Objetivo

Transformar uma ideia inicial em um contexto minimo acionavel para os agentes.

## Passos

1. Ler `README.md`.
2. Ler `AGENTS.md`.
3. Ler `.agents/operating-principles.md`.
4. Ler `.agents/project-architecture.md` quando a stack envolver Next.js, NestJS, Prisma ou PostgreSQL.
5. Preencher ou revisar `.agents/project-context-template.md`.
6. Escolher os especialistas relevantes em `.agents/specialists/`.
7. Identificar comandos reais de instalacao, desenvolvimento, teste, lint e build.
8. Registrar riscos e decisoes tecnicas iniciais.

## Perguntas para responder

- Qual problema o projeto resolve?
- Quem sao os usuarios?
- Qual e o escopo da primeira versao?
- Qual stack sera usada?
- Quais dados serao armazenados?
- Existem riscos de seguranca ou privacidade?
- Como vamos testar?
- Como vamos saber que a primeira entrega esta pronta?
- O frontend deve ser Server Component ou Client Component?
- O backend esta respeitando Domain, Application, Infrastructure e Presentation?

## Saida esperada

Atualize o contexto do projeto e entregue:

- resumo do projeto;
- stack escolhida;
- agentes recomendados;
- riscos iniciais;
- decisoes de arquitetura para frontend e backend;
- proximos passos.
